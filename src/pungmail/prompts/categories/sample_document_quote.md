# 샘플·자료·견적

실제로 요청된 SAMPLE, DOCUMENT, QUOTE만 components에 만든다. 회신에서 완료됐다고 명시된 구성만 completed=true로 표시한다. 수령처, 담당자, 연락처, end user는 근거가 있을 때만 기록한다.

고객이 우리 회사에 요청하고 우리 회사가 같은 스레드에서 자료를 회신한 업무는 끝까지 샘플자료견적이다. 우리 회사가 상류 공급사에 자료를 새로 확보해 달라고 시작한 스레드만 풍림자료요청이다. 동일한 구성은 PENDING과 COMPLETED로 두 번 만들지 말고 완료 근거가 있으면 completed=true인 하나만 만든다.
